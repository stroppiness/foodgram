# Проект Foodgram

## Краткое описание:
API-бэкэнд с SPA-фронтом, представляющие собой платформу для для создания и обмена рецептами разнородных блюд с возможностью подписываться на понравившиеся рецепты, а также на пользователей, которые эти рецепты создают.

## Стек технологий:
1. python
2. django
3. django rest framework
4. nginx
5. gunicorn

## Установка и запуск:
1. Разверните (python -m venv venv) и активируйте (sourse venv/Scripts/activate) виртуальное окружение.
2. Установите зависимости из requirements.txt.
3. Примените миграции python manage.py migrate.
4. Импортируйте csv при помощи python manage.py import_csv.
4. Запустите сервер через manage.py при помощи python manage.py runserver.

## Установка и запуск через docker-compose:
1. Убедитесь, что в вашем рабочем пространстве установлены Docker desktop, а также wsl, если работаете через windows.
2. Разверните (python -m venv venv) и активируйте (sourse venv/Scripts/activate) виртуальное окружение.
3. Запустите оркестр из трёх готовых контейнеров при помощи команды docker compose up. Все образы будут взяты из docker hub, а потому дополнительные действия не требуются.
4. Не забудьте об изменении ALLOWED_HOSTS в settings.py, если параметры вашего запуска отличаются от дефолтных параметров стандартного локального запуска (к примеру, если запускаете на  собственном удалённом сервере).
